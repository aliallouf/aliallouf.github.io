## What's on the site

- **[Portfolio](https://aliallouf.github.io):** background, research experience, publications, research interests, skills, certifications and contact details.
- **[Coursework](https://aliallouf.github.io/coursework.html):** topics and protocols studied in my MSc and BSc courses, with diagrams and interactive demos.

## Built with

Plain HTML and CSS with a little JavaScript. There is no build step, and GitHub Pages publishes the files directly from the `main` branch.

## Project structure

| Path | Contents |
|---|---|
| `index.html` | Main portfolio page |
| `coursework.html` | Coursework page, with its own styles and scripts |
| `assets/style.css` | Styles shared by both pages |
| `assets/photo.jpg` | Profile photo |
| `assets/Ali_Allouf_CV.pdf` | CV for download |
| `assets/favicon.svg` | Browser tab icon |
| `assets/fonts/` | Plus Jakarta Sans font files and license |
| `.nojekyll` | Tells GitHub Pages to publish the files as they are |

## Updating the site

| To change | Edit |
|---|---|
| Introduction | The text between the `INTRO START` and `INTRO END` comments in `index.html` |
| Photo | Replace `assets/photo.jpg`, keeping the same name |
| CV | Replace `assets/Ali_Allouf_CV.pdf`, keeping the same name |
| Certifications | The comment in the Certifications section of `index.html` explains how to add one |
| Courses | Follow "HOW TO EDIT THIS PAGE" near the top of `coursework.html` |
| Shared styles | Edit `assets/style.css`, then raise the `?v=` number in both HTML files |

Everything in this repository is public, including its history. Check files for private details before uploading them.

## Preview locally

From the repository folder, run:

```sh
python3 -m http.server
```

Then open <http://localhost:8000>.
